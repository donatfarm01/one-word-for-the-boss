Build notes for the One Word for the Boss entry.

The entry is a single word written by main.py to the output path the
bounty grades. The word is bottleneck.

First draft. The first word I wrote was ghosting. It is modern and it
catches a real boss habit, the boss who assigns work and then cannot be
reached. But ghosting is borrowed from dating slang, so it leans on a
caption in the reader's head, and it fits an office boss better than a
boss in a kitchen or a warehouse.

Revision. I changed the word to bottleneck. It is a better entry on the
judge's own order of criteria. It is a single word a person would
actually say about the boss they report to. It is funny on its own,
because the image is immediate: everything in the team queues up behind
one person. It rings true, because almost every boss is the point every
approval and every decision has to pass through. It is fresh, because it
is not the first word anyone reaches for, which would be micromanager or
bossy. And it travels: a kitchen, a warehouse and an office all have a
bottleneck, and nobody needs the industry explained to get the joke.

Validation. I ran main.py and read back the file it wrote. The file
holds exactly the word bottleneck, ten characters, ten bytes, no spaces,
no trailing newline, inside the one to thirty character gate.

Layout. The repository holds main.py at the root, a readme with the
three make.fun badges linked to the bounty page, and an MIT license
carrying its SPDX identifier line.
